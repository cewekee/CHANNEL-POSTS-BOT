# CHANNEL POSTS BOT

Автономный постер для Telegram-канала в стиле ScalpLedger. Работает на GitHub Actions, сервер не нужен.

## Что публикует
| Тип | Как выглядит | Когда |
|---|---|---|
| Утро | эмодзи + **приветствие**, BTC за сутки с комментарием, призыв к реакциям | раз в день, случайно 09:00–12:00 |
| Шутка | эмодзи + одна строка про жизнь трейдера | по расписанию |
| Мем | картинка: подпись сверху, оранжевый график с меткой («Я купил»), панчлайн снизу + подпись | по расписанию |
| Факт | карточка «ФАКТ» с датой, текстом и львом в костюме + подпись | до 2 в день |

Между постами — случайно 1–2,5 часа. Ночью (00:30–09:00) тишина. Два одинаковых типа подряд не идут.
Шутки и мемы генерирует Claude (если задан ключ), иначе берутся из встроенного банка. Факты — только из проверенного списка в `content.py`.

## Запуск (один раз)
1. **Settings → Secrets and variables → Actions → New repository secret**:
   - `BOT_TOKEN` — токен бота от @BotFather
   - `CHAT_ID` — `@имя_канала` или `-100…`
   - `ANTHROPIC_API_KEY` — необязательно, для свежих шуток и мемов
2. Добавьте бота **администратором** канала с правом публикации.
3. **Actions → Channel posts → Run workflow**, в поле `force` впишите `meme` — проверка, что пост пришёл.

Дальше всё идёт само.

## Кастомные эмодзи как в ScalpLedger
Перешлите боту в личку несколько постов ScalpLedger. При следующем запуске (≤10 мин) бот сохранит их ID в `emoji.json`, ответит «Добавил новых эмодзи: N» и начнёт ставить их в посты.
Если Telegram не разрешит боту кастомные эмодзи, пост автоматически уйдёт с обычными.

## Настройки
В начале `bot.py`: `MIN_GAP`/`MAX_GAP` (минуты), часы тишины, окно утреннего поста, доли типов (`WEIGHTS`). Тексты — в `content.py`, внешний вид картинок — в `render.py`, лев — `assets/lion.b64` (JPEG в base64).
